## 1. Overview
This Privacy Policy governs the use of **GenieACS Mobile Client** developed by **Alijaya Network**. The application is an administrative client tool for managing network devices (ONT/ONU/CPE) via a user's own TR-069 CWMP / GenieACS server.

## 2. Data Collection & Privacy Commitment
GenieACS Mobile Client is designed as a direct client-to-server utility. **We do not collect, sell, monetize, or harvest user data.** All TR-069 communications occur directly between your mobile device and your configured GenieACS NBI server.

## 3. Permissions & Purpose
- **Server Credentials & Preferences:** Stored securely on your device using Android private app storage. Never transmitted to third parties.
- **Location (`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`):** Used only when viewing the Network Map to display technician GPS location relative to ODPs and client modems, and for launching navigation routes. GPS data is processed locally and never uploaded to remote tracking servers.
- **Microphone (`RECORD_AUDIO`):** Used on-device only when the optional Voice Assistant is triggered. Audio is never recorded, stored, or sold.
- **Network (`INTERNET`, `ACCESS_NETWORK_STATE`):** Used to communicate with your GenieACS NBI server (Port 7557) to view and manage device parameters.

## 4. Third-Party Integrations
- **Google Gemini API (Optional):** Used only if an API key is provided for voice assistant queries.
- **OpenStreetMap / Leaflet:** Used for rendering map tiles without transmitting personal data.

## 5. Data Deletion & Retention
Users retain full control over stored data. You can delete all data at any time by:
- Logging out via the application menu.
- Clearing application data via Android Settings.
- Uninstalling the application.
